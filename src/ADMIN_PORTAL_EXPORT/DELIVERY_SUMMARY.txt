🐛 TROUBLESHOOTING QUICK REFERENCE
================================================================================

Port Already In Use:
  → Kill process: lsof -i :5000 | awk '{print $2}' | xargs kill -9

Cannot Connect to Database:
  → Check PostgreSQL running: psql postgres
  → Or start it: brew services start postgresql (macOS)

Login Fails:
  → Clear browser cache: F12 → Application → Clear Storage
  → Try again with: admin@example.com / admin123

API Returns 404:
  → Check backend is running in other terminal
  → Verify VITE_API_URL in frontend/.env is http://localhost:5000/api

Module Not Found:
  → Run npm install in both backend and frontend
  → Delete node_modules and try again

CORS Error in Console:
  → Check backend .env has: FRONTEND_URL=http://localhost:5173
  → Restart backend server

For more: See TROUBLESHOOTING.md (50+ issues covered)
